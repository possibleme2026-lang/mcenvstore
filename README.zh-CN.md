## 这是什么

一个单文件、无构建、零依赖的深色主题落地页。十一个 section、内嵌 EN/ZH 词典、
滚动进场动画、以及一个真正可用的环境市场筛选——全部装在一个 `index.html`
加四个自托管字体文件里。

页面论证一个观点：**Agent 能力的长尾，取决于谁有权决定什么值得训练。**
如果任务由少数几家模型公司挑，Agent 的能力就永远被锁在它们的视野里。
所以页面主张把「贡献环境」做得像「发一条视频」一样容易，并展示支撑它的各个部件。

## 核心理念

### 根本矛盾

今天训练环境有两个来源：模型公司自己合成，或向数据公司采购。两者都被同一件事卡住——
一小群人替所有人决定哪些任务重要。覆盖范围受限于团队规模与领域知识，而且数据公司再大，
也不知道每个行业、每家公司、每款小众软件里真正值得训练的任务是什么。

> 用有限的劳动力去追无限的任务分布——这是根本矛盾。

### 为什么可以像抖音

抖音不生产内容，内容量却超过任何电视台。页面把这套逻辑搬到环境上：
会计知道对账的坑、律师知道合同审查的关键条款、SRE 知道线上事故的排查路径。
他们都不需要懂 RL、不需要写验证器，只需要知道：这个任务，Agent 应该学会。

## 平台会做什么

页面主张这四项能力应该是平台级基础设施，而不是每家公司重复造轮子：

### 1. 自动验证器生成

上传任务并描述「什么算完成」，平台按任务类型自动生成验证器：
代码任务从参考实现生成测试；规则类任务把标准转成可执行检查；
文档任务从期望输出合成 rubric；开放式任务从多个参考解构造分组 rubric。
贡献者只需确认或微调，不需要从零写代码。

### 2. 反作弊审计

环境公开后模型会想尽办法作弊，这是一场军备竞赛。平台上线的每个环境先跑一个
「Hack Agent」自动探测答案泄漏、无关动作绕过验证、伪正确结果构造。
发现就修，修不了就下架；训练中持续审计轨迹，作弊奖励置零。

### 3. 评分即服务（Grader as a Service）

二元的通过/失败不够。提供两种评分模式：**GRS** 离线合成任务专属 rubric，
以及 **GAR** 在线分组比较与优势再分配。模型公司调用统一 API，
不需要自己实现评分器。

### 4. 隔离与标准化

每个环境运行在自己的容器里，统一 Gym 接口——可重置、可复现、可版本化。
网络隔离、文件隔离、资源配额都是默认配置。

## MCP 采集器

更轻的贡献方式：把采集器装进你每天在用的 Agent 产品里。
只需在 Codex、Cursor、Claude Code、MiMo Code 等任一产品的配置里加一行 MCP 配置，
然后照常工作。

采集器在后台静静监听，只在发现「高价值片段」时标记——你和 Agent 来回很多次、
你纠正它的错误、你最后说「好了就这样」。它把这段工作流本地打包成
**环境草稿**，然后做**本地匿名化**：公司名、项目名、人名、邮箱、API key、
真实财务数字全部替换为占位符，结构保留。你不点「确认贡献」，数据永远不会离开你的设备。

## 环境市场

GitHub 式的浏览与协作，App Store 式的评分与消费。六个示例环境覆盖
财务、法律、运维、教育、客服、代码，并带一个七个分类都能用的筛选。

> 一个会计贡献的财务报表对账环境，可能比模型公司合成的一百个通用财务任务更有价值。

## 激励设计

收益分成（模型公司支付的 token 按比例分配给贡献者）、声望积分（社区评分、
早期环境评审权、新功能内测资格）、访问权回馈（贡献环境可换取其他环境的访问权
或优先测试新模型）。

页面给出的「为什么比视频更有累积性」的论证是：视频流量会衰减，
但一个经过验证的好环境可以被反复使用、迭代、组合，并随着更多模型消费而持续增值。

## 技术说明

### 架构

纯 HTML、CSS 与原生 JavaScript，全部在一个文件里。无打包器、无框架、
无运行时依赖、加载时不发任何网络请求。

### 国际化

三个属性驱动的钩子支撑 EN/ZH 切换，所以加一门语言是改词典而不是改标记：

| 属性 | 作用于 |
|---|---|
| `data-i18n` | 元素的 `innerHTML`（允许内联 `<br>` 与渐变 span） |
| `data-i18n-placeholder` | 输入框 `placeholder` |
| `data-i18n-label` | `data-label`，由 CSS `::before` 的 content 消费 |

所选语言会持久化到 `localStorage`，并在首次绘制前重新应用。

### 自托管字体

Inter（400/500/600）与 JetBrains Mono（400）以本地 `woff2` 形式从
`assets/fonts/` 提供——共约 100 KB，不依赖任何第三方 CDN。
这让页面完全自包含，也避免依赖任何厂商的字体托管服务。

### 响应式已实测

布局是在三种宽度下用 `getBoundingClientRect()` 量出来的，而不是靠肉眼看截图：

| 视口 | 越界元素数 |
|---|---|
| 390 px | 0 |
| 768 px | 0 |
| 1440 px | 0 |

## 本地运行

无需安装。任意静态服务器都可以：

```bash
git clone https://github.com/possibleme2026-lang/mcenvstore.git
cd mcenvstore
```

```bash
python -m http.server 8000
# 然后打开 http://localhost:8000
```

直接用 `file://` 打开 `index.html` 也能跑，因为没有模块导入。

## 状态与已知限制

这是一个**设计原型**，页面本身对哪些部分是示意也说得很清楚：

- 等待列表表单**不会**提交到任何地方。它只校验邮箱并把按钮文案换掉。
  本仓库没有后端。
- 六个市场环境及其评分、价格、作者名都是**用于排版演示的示例数据**。
- MCP 配置块与匿名化预览卡片是**示意 UI**，不是可用的采集器。
- 合作伙伴 logo（Codex、Cursor、Claude Code、MiMo Code）是「第一批合作伙伴正在加入」
  位置里的占位符，不代表任何背书或隶属关系。
- 导航与页脚指向 Docs / API / Team / Blog 的链接都指向 `#`——这些页面还不存在。
